# Primus-Human-3000 🌀

Интерактивный сайт-симулятор **«Панель управления человеческой стиральной машиной Primus-Human-3000»**, созданный на основе фотографии девушки внутри барабана промышленной стиральной машины.

Сайт представляет собой футуристичный пульт управления с неоновым дизайном, интерактивными элементами управления, динамическим логом событий и синтезированными звуковыми эффектами.

## 🚀 Функционал

- **4 забавных режима стирки**:
  - `🧘 Деликатный детокс` (мягкая чистка от уведомлений и соцсетей)
  - `🕺 Пятничный отжим` (подготовка к выходным, вытряхивание дедлайнов)
  - `⚡ Турбо-Креатив` (разогрев процессора до 75°C и разгон синапсов до 1200 об/мин)
  - `🌀 Сингулярность` (квантовый отжим и поиск пропавших носков в параллельных мирах)
- **Ручные параметры**: регулировка температуры (от Ледяной до Лавы) и скорости отжима (до Сверхзвука 1600 об/мин).
- **Интерактивные добавки**: Жидкий оптимизм, Мотивация 100%, Волшебная пыльца, Дзен-эссенция.
- **Web Audio API Звуки**: полностью синтезированное аудиосопровождение (шум воды, нарастающий свист мотора при отжиме, клики кнопок, финальный 8-битный джингл).
- **Экстренная кнопка**: кнопка аварийной остановки (`EMERGENCY STOP`) с сигнализацией и сбросом всех датчиков.
- **Реалистичные анимации**:
  - Вращение барабана и фото с разной интенсивностью и эффектом размытия в зависимости от скорости.
  - Наполнение барабана водой и пузырьками.
  - Вибрация корпуса машинки при сильном отжиме.

## 🛠 Запуск проекта

Проект не требует установки зависимостей или сборки. Это чистый HTML, CSS и JavaScript.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/lowcostcleaning/human-washer-3000.git
   ```
2. Откройте файл `index.html` в любом браузере:
   - Либо просто дважды кликните по файлу `index.html`.
   - Либо запустите локальный сервер (например, `python3 -m http.server 8000` в папке проекта) и перейдите на `http://localhost:8000`.
